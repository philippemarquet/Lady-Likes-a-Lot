Lady Likes-a-Lot — pagina met stories
=====================================
Inhoud: index.html + map img/ (alles staat in deze map, geen server nodig).

Online zetten met GitHub Pages:
1. Maak op GitHub een nieuwe repo (bv. "ladylikesalot"), zet hem op Public.
2. Upload de INHOUD van deze map (index.html + map img) naar de repo.
3. Repo > Settings > Pages > Source: "Deploy from a branch", branch "main", map "/ (root)" > Save.
4. Na 1-2 minuten staat de pagina op https://<jouw-gebruikersnaam>.github.io/ladylikesalot/
5. Die URL geef je aan make_qr.py:  python3 make_qr.py https://....github.io/ladylikesalot/
   -> maakt qr.png (zwart-wit, scherp voor in de krant).
